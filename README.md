# Shopping Cart

## What it is
A shopping cart with persistent state, built in vanilla TypeScript.
Products are fetched from an API (dummyApi); the cart survives page reloads via localStorage.

## Purpose
Practice state management with an encapsulated store, derived state,
and browser persistence — the core patterns behind Redux/Pinia/Vuex, built by hand.

## Stack
Vanilla TypeScript, Vite (or tsc), localStorage.
